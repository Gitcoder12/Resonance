# Agent Instructions — Resonance

The repository is concept-stage. Read the roadmap before implementing a real provider.

- Start with deterministic mock adapters and fixed prompt fixtures.
- Treat routing recommendations as policy decisions that must be explainable.
- Never add API keys, forward user prompts or incur provider costs autonomously.
- Validate provider timeouts, rate limits, errors and fallback logic.
- Measure cost, latency and task quality with stated methods.
- Work on a branch; open a PR and leave merge/provider activation to a human.
