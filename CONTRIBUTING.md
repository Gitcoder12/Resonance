# Contributing to Resonance

This is a concept-stage project. Begin with a deterministic mock routing evaluation.

1. Read README.md and FEATURE_UPGRADE_PLAN.md.
2. Select one routing criterion or provider-interface task.
3. Work on a feature branch.
4. Add fixed prompt fixtures and tests for routing/fallback decisions.
5. Do not use real user prompts or API keys in tests.
6. Document latency/cost method and provider privacy behavior.
7. Open a PR with exact tests and limitations.

Human maintainers approve merges, credentials and external provider connections.
